# 产品定位与操作来源

日期：2026-11-05。唯一定位：**糖衡智管——面向医护健康管理人员的智能监测与随访监管工作台**。

一套工作台、一个Agent、合成病例演示。没有独立患者端、医院HIS、机构权限系统或角色切换。监管总览跨病例汇总待办；患者详情和各业务页面绑定明确患者ID。

工作人员监督记录、管理事件、证据、任务、随访与人工复核。Agent读取已保存事实和偏好，在后端安全校验下检索、提问、规划与调用工具，保留run_id和结果。事件是健康管理规则的输出，不能称为诊断或“AI临床风险分级”。

常驻标识：`参赛演示 · 合成患者数据 · 非医疗器械`。Agent不诊断、不开处方、不改药/停药/调整胰岛素剂量、不独立实施医疗处置。高风险转人工专业复核。

| 来源 | 界面与后端行为 | 真实性限制 |
| --- | --- | --- |
| 医护演示工作人员 | 完成及人工改期发送`changed_by=staff_demo`，版本记录实际保存 | 此字符串不是认证后的工作人员身份 |
| 模拟患者答复 | 明示合成演示并勾选确认，调用问题回答API | API无独立代答操作者字段，不能永久区分真实患者和工作人员代答 |
| 模拟偏好 | 使用后端允许source，并明确模拟反馈来源 | 勾选确认不是患者身份认证；不允许将工作人员猜测当患者确认 |
| 系统规则 | records返回的automation、事件及作业；普通完成后规则复评 | 不归功于模型自主决策；手动tick不等于持续后台运行 |
| 确定性规划器 | run.llm_mode=mock，工具和SQLite实际执行 | 不是厂商模型调用 |
| 真实模型工具 | real且具体trace含原生工具响应元数据时标明 | 仅real配置不证明原生调用；安全门拒绝须单独说明 |

界面默认给出业务步骤、实际参数与结果、任务/问题/复评变化、证据和拒绝原因；完整JSON保留为折叠调试视图。缺失阶段显示未返回，不编造“模型思考过程”。

仅允许本机合成演示。前端隐藏按钮、勾选确认和工作人员来源字符串都不是服务端授权；公开部署须由A补认证、数据权限与有效审计，本轮不宣称完成。
