## 必须在 PPT 中如实标注

1. 这是**演示作品**，不是医疗器械软件，不提供诊断/处方/用药调整。
2. 患者均为合成虚构数据。
3. 本次演示的 Agent 运行模式：若为 `mock`，必须写明"确定性策略规划器，未调用真实模型"；
   若接入 `real` 模式，注明模型名与端点类型，并附真实 smoke test 记录。
4. 测试结果只说明特定合成场景下的系统行为，不代表临床有效性。
